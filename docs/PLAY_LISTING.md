# Play 스토어 등록정보 (Voylog)

콘솔에 그대로 붙여넣을 문구와, 설문에 어떻게 답해야 하는지. 등록 절차
자체는 `travel_youtube_app/docs/RELEASE.md`.

## 앱 이름 (30자 이내)

```
Voylog - 여행 영상 동선 플래너
```

## 짧은 설명 (80자 이내)

```
유튜브 여행 영상 속 장소를 자동으로 찾아, 하루 동선으로 짜 드려요.
```

## 자세한 설명 (4000자 이내)

```
가고 싶은 곳이 담긴 여행 브이로그, 보고 나면 어디였는지 다시 찾기 어렵죠.
Voylog는 유튜브 영상 주소만 넣으면 영상 속 장소를 대신 찾아 정리해 줍니다.

■ 영상 속 장소를 자동으로
유튜브 주소를 붙여넣으면 자막과 화면 속 글자를 읽어 장소를 뽑아내고,
지도 위 좌표와 주소까지 붙여서 카드로 보여줍니다. 카드의 시간을 누르면
영상의 그 장면으로 바로 이동합니다.

■ 해시태그와 추천 마법사로 영상 찾기
가고 싶은 지역과 테마, 여행 기간을 고르면 어울리는 브이로그를 찾아 줍니다.

■ 하루 동선을 AI가
마음에 든 장소를 북마크해 두고, 여행의 각 날짜마다 출발 숙소와 도착
숙소를 고르면 가장 덜 걷고 덜 돌아가는 순서로 동선을 짜 줍니다.
자동차, 도보, 대중교통 중에 고를 수 있습니다.

■ 지금 내 주변
현재 위치와 시각을 기준으로 가까운 곳을 음식점, 카페, 놀거리 탭으로
나눠 보여줍니다. 취향 태그를 설정하면 취향에 맞는 순서로 정렬됩니다.

■ 뚜벅이 코스
지역만 고르면 서로 걸어 다닐 수 있는 거리의 장소들로 코스를 만들어
줍니다. 구간마다 걷는 시간과 버스 노선을 알려주고, 카카오맵 길찾기로
바로 열 수 있습니다.

■ 다른 사람의 동선 구경하기
직접 만든 동선을 공개 피드에 올리고, 취향이 비슷한 사람의 동선에
좋아요를 누를 수 있습니다. 여행 전체 일정은 링크 하나로 공유됩니다.

- 장소 정보 일부는 한국관광공사 TourAPI와 소상공인시장진흥공단 상가정보를
  이용합니다(공공누리 제1유형).
```

## 데이터 보안(Data safety) 설문 답변

코드가 실제로 하는 일 기준이다. 바꾸면 이 표도 같이 고쳐야 한다.

| 항목 | 수집 | 공유 | 필수 | 용도 |
| --- | --- | --- | --- | --- |
| 이름(닉네임) | 예 | 아니오 | 필수 | 계정 관리 |
| 이메일 주소 | 예 | 아니오 | 필수(카카오는 동의 시) | 계정 관리, 문의 답변 |
| 사진 | 예 | 아니오 | 선택 | 프로필 사진 |
| 대략적 위치 / 정확한 위치 | 예 | 예 | 선택 | 주변 장소 추천, 길찾기 |
| 앱 활동(북마크·일정·조회 기록) | 예 | 아니오 | 선택 | 추천 개인화 |
| 기기 ID | 예 | 아니오 | 선택 | 푸시 알림 발송 |

- **전송 중 암호화**: 예 (모든 통신 HTTPS)
- **데이터 삭제 요청 수단 제공**: 예 (앱 내 회원 탈퇴)
- **위치를 "공유"로 체크하는 이유**: 주변 추천과 경로 계산을 위해 좌표가
  카카오 지도 API로 전달된다. 위도·경도 자체는 서버에 저장하지 않고
  `0-200m` 같은 반경 구간만 기록한다(`behavior.service.js`).
- **영상 분석**: 자막과 영상 설명 텍스트가 OpenAI/Anthropic API로 전달된다.
  이용자 개인정보가 아니라 공개된 유튜브 영상의 내용이다.

## 콘텐츠 등급 설문

폭력·성적 내용·도박·약물 전부 "아니오". 이용자 간 소통은 **있음**으로
답한다 — 공개 동선 피드에 이용자가 직접 입력한 제목이 올라간다.
광고 포함 여부는 **없음**.

```
https://voylog.duckdns.org/privacy
```

기간에는 서버를 내리지 말 것.**
