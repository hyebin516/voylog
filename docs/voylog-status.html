영상 분석 & 탐색

FR-01FR-02FR-03 FR-04FR-09FR-10

유튜브 URL 하나로 영상 속 장소를 찾아내고, 해시태그나 지역/테마/기간 선택으로도 영상을 탐색할 수 있다. 세 가지 탐색 경로가 결과적으로 같은 인프라를 공유한다.

  • ✓URL 분석 — 자막 추출 → LLM 파싱(OpenAI→Claude 폴백) → Kakao 지오코딩 → 장소 카드. 동일 URL은 Redis→DB 캐시로 즉시 반환.
  • ✓해시태그 탐색 — YouTube Data API 키워드 검색 결과를 카드 목록으로 제공.
  • ✓지역/테마/기간 추천 마법사 — 지역 → 테마 → 기간 3단계 선택 후, 해시태그 탐색과 동일한 검색 인프라로 브이로그 추천.
  • ✓타임스탬프 이동 & 장소 카드 — 영상 속 등장 시점으로 바로 이동, 신뢰도/출처(자막·해시태그·설명·제목) 표시.

여행 동선

FR-07

여행 하나에 여러 날짜를 담고, 날짜마다 독립적으로 시작·종료 호텔을 골라 AI가 방문 순서를 최적화한다.

  • ✓여행 · 일자 구조 — 여행(trip) 아래 1일차, 2일차… 를 누적 저장. 같은 여행 안에서도 날짜마다 호텔 조합이 다를 수 있음 (예: 1일차 A→B호텔, 2일차 B호텔 왕복).
  • ✓왕복 / 호텔 간 이동 자동 판별 — 시작=종료 호텔이면 왕복, 다르면 호텔 간 이동으로 서버가 판별.
  • ✓AI 동선 최적화 — 장소 2~10개, Kakao Mobility 이동 시간 기반 TSP 스타일 순서 최적화.

계정

FR-08FR-14

카카오 소셜 로그인과, 이메일+비밀번호 기반 네이티브 회원가입 두 경로를 모두 지원하며 동일한 JWT 발급 흐름을 공유한다.

  • ✓카카오 로그인 — OAuth 토큰 검증 → 최초 로그인 시 자동 가입 → JWT 발급.
  • ✓네이티브 회원가입 — 이메일 입력 → 6자리 OTP 이메일 인증(SMTP, 5분 유효, 5회 시도 제한) → 비밀번호(8자 이상)·닉네임 입력 → 가입 완료.
  • ✓네이티브 로그인 — bcrypt 해시 비교. 카카오 전용 계정으로는 로그인 불가(비밀번호 미보유).
users.password_hash email_otps POST /auth/signup/request-otp POST /auth/login
