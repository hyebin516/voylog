# 공개 정책 문서

이 디렉토리의 `.md` 파일은 `static-doc.controller.js`가 **그대로 HTML로 변환해
공개 주소로 서빙한다.** 고치면 백엔드를 다시 빌드·배포해야 반영된다.

| 파일 | 공개 주소 |
| --- | --- |
| `privacy-policy.md` | `https://<도메인>/privacy` |
| `terms-of-service.md` | `https://<도메인>/terms` |

**파일 안에 주석이나 메모를 남기지 말 것.** 마크다운 주석(`<!-- -->`)은 화면에는
안 보여도 공개된 페이지 소스에 그대로 남는다. 실제로 "법률 자문을 받은 문서가
아니다" 같은 내부 메모가 Play 스토어 심사용으로 제출한 개인정보처리방침
소스에 노출돼 있었다(2026-11-10 제거).

두 문서 모두 **현재 코드가 실제로 하는 일**을 적은 것이지 법률 자문을 받은
문서가 아니다. 개인정보처리방침은 Google Play가 요구하는 네 가지를 충족해야
한다 — 유효한 SSL, 로그인·지역 제한 없는 전 세계 접근, PDF가 아닌 웹페이지,
그리고 **데이터를 넘기는 제3자의 유형을 빠짐없이 공개**(현재 카카오·OpenAI·
Anthropic·Firebase 명시).
