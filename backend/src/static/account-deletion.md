# Voylog 계정 및 데이터 삭제 안내

**앱 이름: Voylog (Voylog - 여행 영상 동선 플래너)**
**개발: 럭키비키 (김혜빈 · 최나경)**

이 문서는 Voylog 계정과 그에 딸린 데이터를 삭제하는 방법, 그리고 삭제하면
무엇이 지워지고 무엇이 얼마나 남는지를 설명합니다.

---

## 1. 계정 삭제 — 앱에서 바로

가장 빠른 방법입니다. 앱에 로그인할 수 있다면 이 방법을 쓰세요.

1. Voylog 앱을 엽니다
2. 오른쪽 아래 **내 페이지** 탭을 누릅니다
3. **설정** 으로 들어갑니다
4. 맨 아래 **회원 탈퇴** 를 누릅니다
5. 안내에 따라 확인하면 계정이 즉시 삭제됩니다

탈퇴하면 로그아웃되고, 같은 계정으로 다시 로그인할 수 없습니다. 같은
이메일이나 같은 카카오 계정으로 **새로 가입하는 것은 언제든 가능합니다.**

## 2. 계정 삭제 — 이메일로 요청

비밀번호를 잊었거나 카카오 계정에 접근할 수 없어 로그인하지 못하는 경우,
아래 주소로 요청하실 수 있습니다.

- **voylog.help@gmail.com**
- 제목에 **계정 삭제 요청** 이라고 적어 주세요
- 본문에 가입하신 **이메일 주소** 또는 앱에서 쓰던 **닉네임** 을 적어 주세요

본인 확인 후 **영업일 기준 7일 이내** 처리하고, 처리 결과를 회신합니다.

## 3. 계정을 그대로 두고 데이터만 지우기

계정을 없애지 않고도 앱 안에서 아래 데이터를 직접 지울 수 있습니다.

| 지우고 싶은 것 | 지우는 곳 |
| --- | --- |
| 북마크한 장소 | 북마크 탭에서 해당 장소의 북마크 해제 |
| 북마크 폴더 | 북마크 탭 → 폴더 → 삭제 |
| 여행과 날짜별 동선 | 여행 탭 → 해당 여행 → 삭제 |
| 저장한 뚜벅이 코스 | 여행 탭 → 저장한 코스 → 삭제 |
| 공개 피드에 올린 동선 | 홈 피드의 내 게시물 → 게시 취소 |
| 숙소(호텔) 정보 | 동선 만들기 화면의 숙소 목록에서 삭제 |
| 취향 태그와 취향 벡터 | 내 페이지 → 취향 설정 → 초기화 |
| 프로필 사진 | 내 페이지 → 프로필 수정 → 사진 삭제 |

위 목록에 없는 데이터를 지우고 싶으시면 **voylog.help@gmail.com** 으로
무엇을 지우고 싶은지 적어 보내 주세요.

---

## 4. 계정을 삭제하면 지워지는 데이터

- 계정 정보: 닉네임, 이메일 주소, 비밀번호, 프로필 사진
- 북마크한 장소와 북마크 폴더
- 여행, 날짜별 동선, 저장한 숙소 정보
- 저장한 뚜벅이 코스
- 취향 태그와 취향 임베딩(추천 개인화에 쓰이던 벡터)
- 추천 학습을 위해 쌓인 행동 기록
- 푸시 알림을 받던 기기 등록 정보와 알림 설정

## 5. 계정을 삭제해도 남는 데이터

| 남는 것 | 왜 남는지 | 보관 기간 |
| --- | --- | --- |
| 공개 피드에 게시한 동선 | 작성자 정보를 지운 익명 상태로 남습니다. 다른 이용자가 이미 보고 좋아요를 누른 공개 게시물이기 때문입니다. 탈퇴 전에 직접 **게시 취소** 하시면 완전히 사라집니다 | 직접 게시 취소하기 전까지 |
| 분석된 영상과 장소 정보 | 특정 이용자의 것이 아니라 **영상 자체의 공개 정보**입니다(영상 제목, 등장 장소, 좌표). 누가 분석했는지는 기록하지 않습니다 | 계속 보관 |
| 고객센터 문의 내역 | 문의에 답변하고 같은 문제가 반복되는지 확인하기 위해 보관합니다 | 처리 완료 후 3년 |
| 신고 접수 내역 | 신고가 누구를 향한 것이었는지 확인하기 위해 보관합니다 | 처리 완료 후 1년 |
| 서버 접속 기록 | 장애를 추적하고 악용을 막기 위해 보관합니다. 이용자를 특정하는 정보는 담지 않습니다 | 3개월 |

삭제된 계정 정보는 **즉시 접근할 수 없게 되며, 30일 이내에 백업본에서도
제거**됩니다.
