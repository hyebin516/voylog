# 에셋 출처와 이용권

앱에 들어가는 이미지와 글꼴이 어디서 왔고 어떤 조건으로 쓰는지 적는다.
"이 사진 어디서 났느냐"는 질문은 스토어 심사나 발표 자리에서 실제로 나오며,
그때 답할 근거가 저장소 안에 있어야 한다.

## 이미지

| 파일 | 출처 | 비고 |
| --- | --- | --- |
| `images/intro/landscape.png` | **AI 생성** | 온보딩 배경 |
| `images/intro/video-sea-clean2.png` | **AI 생성** | 온보딩 배경 |
| `images/intro/map-clean.png` | **AI 생성** | 온보딩 일러스트 |
| `images/intro/t1.png`, `t2.png`, `t3.png` | **AI 생성** | 온보딩 썸네일 |
| `icon/app_icon*.png` | 직접 제작 | `tool/make_app_icon.py`가 생성. 앱 안 로고(`VoylogLogoMark`)와 같은 도형 |

온보딩 이미지는 전부 생성형 AI로 만든 것이며 스톡 사진이나 제3자 저작물을
가져온 것이 아니다. 실존 인물·상표·저작물이 식별되는 요소는 포함돼 있지
않다.

## 글꼴

세 글꼴 모두 **SIL Open Font License 1.1**로 배포되며, 상업적 이용과 앱
내장이 허용된다. OFL은 **고지 의무**가 있어 라이선스 전문을 앱에 포함한다
(설정 > 오픈소스 라이선스).

| 글꼴 | 쓰는 곳 | 라이선스 |
| --- | --- | --- |
| Pretendard | 본문 전체 | SIL OFL 1.1 |
| Poppins | 온보딩 워드마크 | SIL OFL 1.1 |
| Caveat | 손글씨 캡션 | SIL OFL 1.1 |

`google_fonts` 패키지의 런타임 다운로드는 꺼져 있고 파일을 직접 번들한다.

## 지도·장소 데이터

| 출처 | 조건 |
| --- | --- |
| 카카오 지도 · 로컬 · 길찾기 | 카카오 서비스 약관에 따름. 지도에 카카오 로고 표시 |
| 한국관광공사 TourAPI | 공공누리 제1유형 (출처표시) |
| 소상공인시장진흥공단 상가(상권)정보 | 공공누리 제1유형 (출처표시) |

공공데이터 두 건은 **출처표시가 의무**라 장소 목록 화면 하단에
`DataSourceAttribution`으로 표시한다. 이미지는 항목별 저작권이 달라
적재하지 않는다.

## 오픈소스 의존성

Flutter 패키지들의 라이선스는 `showLicensePage`가 빌드 시점에 모아서
보여준다(설정 > 오픈소스 라이선스). 목록을 손으로 관리하지 않는 이유는
패키지를 추가할 때마다 빠뜨리기 때문이다.
